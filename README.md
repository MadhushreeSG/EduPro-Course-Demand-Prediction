# EduPro Course Demand Prediction

This project predicts course enrollment demand and revenue for the EduPro online learning platform using machine learning.

## Features
- Course demand prediction
- Revenue estimation
- Interactive Streamlit dashboard

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn

## Model
Random Forest Regressor trained on course, instructor, and transaction data.

## Dashboard
Users can input:
- Course price
- Duration
- Course rating
- Instructor experience

The model predicts expected enrollments and revenue.
